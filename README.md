# 江雪・雪境漫遊 1.4.4

[在 GitHub Pages 開啟遊戲](https://cfsthk.github.io/jiangxue-ink-world/)

GitHub Actions 會在推送 main 分支時，把現有 dist 資料夾部署至 GitHub Pages，無需安裝套件或建置。也可在 Actions 手動執行「Deploy Jiangxue to GitHub Pages」。

為香港小五至小六設計的 Three.js 半開放水墨探索遊戲。學生從面向出口的馬車後開始，沿山路墨點依次尋回五件行李，認識柳宗元離京、貶謫與思念故人的背景。建議課堂預留15–20分鐘。

## 開啟與驗證

Three.js 已附在專案中，不需安裝套件。以Python3啟動HTTP，Node.js檢查程式與測試：

```sh
npm run dev
npm run check
npm test
```

瀏覽 `http://127.0.0.1:4187/`；請經HTTP開啟，不能直接雙擊index.html。

主畫面以書法呈現作者、標題及完整四句詩，「步入江雪」位於右下方的白色江面，避開前景岩石。右上有五個完全相同的深灰毛筆空心圓圈（#4a4a4a），使用同一張含飛白與不規則筆緣的透明圖像；每尋回一件便少一圈。進場時以書法顯示「沿着墨點，尋回五件散落的行李。拾起行李，了解柳宗元的往事。」，在實際探索約十二秒後淡去；暫停時保留閱讀時間。

## 操作與流程

WASD或上下鍵行走，左右鍵轉身；按住畫面拖曳環顧。觸控在左側按住拖動行走，右側拖曳環顧。走近物件，點宣紙動作按鈕或按E，先移開遮擋物，再拾起。動作進行時不顯示提示文字。Escape開啟暫停選單。選單已移除「回到起點」、「觀看美術原圖」和可見字體署名；字體來源與授權保留在本文件及字體資料夾。

| 次序 | 行李 | 環境操作 | 往事 |
|---|---|---|---|
| 1 | 官帽 | 搖樹，待帽子落下 | 在朝任職與抱負 |
| 2 | 改革文稿卷筒 | 挪開小石 | 805年與同伴參與改革 |
| 3 | 貶官文書 | 挖開積雪 | 改革失敗，被貶離京 |
| 4 | 行程布地圖 | 移枝拉出地圖 | 途中由邵州改貶永州 |
| 5 | 舊友送別信 | 撥開蘆葦 | 同伴分散、遠行的孤獨 |

拾起即隱藏場景物件，顯示其往事；按「收好」後，墨點直接指向下一件。畫面沒有手持模型。五件全部找齊後，墨點才帶回馬車，一次放回所有行李。途中不能提早交回。

交回後自動開啟「查看馬車」，可點五件物件重讀往事。按「收好」會回到清單；按「繼續上路」回到原有江雪主畫面，下次進場為全新一局。遊玩時右上墨點代表仍未尋回的行李，點按該位置可重讀已拾取往事。清單只保留插圖與名稱，不顯示位置、狀態或說明段落。

## 水墨場景與聲音

馬身是連續肩背、頭頸與四腿的真實曲面；馬車有微彎木板、木輪及布篷摺痕。五件物件均有立體布面、紙層、繫帶、纖維與書寫，UV／三向投影將墨洗紋理貼在曲面，並以柔和墨暈處理輪廓。標題、按鈕及物件文字用自由香港楷書，長文用霞鶩文楷TC。

馬車、馬匹、兩崖山口、道路與通行邊界共用同一中心，起始鏡頭不變；馬車填住出口道路。扁平石階、低岸石和岩腳按實際坡度貼地，避免水平石片浮在雪上。保留曲岸、灰藍／灰色江流、舟影與水紋、舟和老翁浮沉、流動山霧、密雪、貼地雪粉、冬季植物及淡去腳印。

聲音以原生Web Audio環境風聲、江水、雪地腳步與枝葉聲為主，保留強弱陣風及背風效果。加入清楚可聞的慢琵琶：撥弦混音增益由0.0095提高至0.055，約為原來的5.8倍；進場或恢復後約1–2秒奏起，每句三至四音，音距約1.5–1.9秒，句後留5–8秒風聲。暫停、靜音或重開會取消樂音，恢復時不補播。沒有呼喚或投石互動。
