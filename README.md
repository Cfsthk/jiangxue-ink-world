# 江雪・雪境漫遊

Three.js 半開放探索原型。繁體中文介面，依柳宗元〈江雪〉的山徑、寒江與孤舟設計。

## 本機開啟

需要 Node.js（只用來做語法檢查）及 Python 3。Three.js 已隨專案附上，不需安裝依賴。

```sh
npm run dev
```

開啟 http://127.0.0.1:4187/ 。請經 HTTP 開啟，不能直接雙擊 index.html。

```sh
npm run check
```

## 操作

- W A S D 或上／下方向鍵：行走；左／右方向鍵：轉身。
- 按住畫面拖曳：環顧。
- E／互動按鈕：走近松枝後落雪、江岸投石、凝望孤舟。
- C／呼喚按鈕：呼喚與回聲。
- Escape：暫停，亦可查看操作說明、選定的美術原圖或回到起點。
- 觸控裝置：左下搖桿移動，右側拖曳環顧。

## 視覺與原型範圍

選定基準圖是 `dist/assets/art-reference.png`（遠山加深灰、石灘加深之前的版本）。進場保留該原圖，再經霧色淡入實際可走動的三維場景。三維地形、岩塊、松樹、舟及人物均有立體表面：岩石用三向投影的乾筆岩紋，枝幹、木板和草蓑用沿物件方向的 UV 筆畫貼圖。近松可繞看；岩石採密分割不規則曲面與共享平滑法線，雪沿同一岩面以高度、坡度與墨暈混合，取消獨立幾何雪帽；雪面有淡墨顆粒、坡影及接地柔暈。江心不放石塊或孤立石柱；不可抵達的對岸有連續低雪岸。四層完整環繞的透明水墨山景，加上最遠連續淡山脊，覆蓋四方並隨遠近淡化。江水以灰藍、淡灰及紙白墨洗分區，破筆水紋緩流，遠岸以霧色銜接。共八條相連山徑，比初版新增三條環線，三十八棵近岸松樹與二十六棵對岸淡墨松。所有近岸樹幹與實際路面邊界至少相隔2.6米；遠樹使用墨松圖減少繪圖負擔。兩岸共四十四塊陸上灰雪岩與不規則灰墨砂礫帶，從山頂也能辨認。這是可試玩的美術與互動原型，未包含正式課堂管理、學生紀錄或完整遊戲內容。

不設詩句獎勵、三級提示、心情選擇題、計分或收集。山路佈局、環境互動與天色均為教學上的藝術想像；詩中的情感可有不同理解。
