# 江雪・山雪途中 1.0

為香港小五至小六設計的 Three.js 半開放水墨探索遊戲。學生從面向出口的馬車後開始，在山徑、松林與寒江之間找回五件行李，認識柳宗元離京、貶謫與思念故人的背景。建議課堂預留 15–20 分鐘，實際時間按閱讀與探索速度而定。

## 本機開啟與檢查

Three.js 已附在專案中，不需安裝套件。Python 3 用來啟動 HTTP，Node.js 用來檢查程式及執行測試。

```sh
npm run dev
npm run check
npm test
```

瀏覽 `http://127.0.0.1:4187/`。請經 HTTP 開啟，不能直接雙擊 `index.html`。

## 操作與流程

- WASD 或上下方向鍵行走，左右方向鍵轉身；按住畫面拖曳環顧。
- 走近物件後點選／輕觸，或按 E：先移開遮擋物，再拾起；返回車後再點車或按 E 放好。
- 觸控：畫面左側按住並拖動以行走，右側拖曳環顧。沒有可見搖桿及底部按鈕。
- 遊玩介面只保留右上環境聲開關及相鄰的 `0/5`。點件數可重讀已拾起物件的往事。
- C 呼喚，聽見回聲；Escape 暫停並開啟操作、重開和美術原圖選單。進場前也可查看操作方式。

| 次序 | 行李 | 環境操作 | 往事 |
|---|---|---|---|
| 1 | 官帽 | 搖樹，等帽子落下 | 曾在朝廷任職與抱負 |
| 2 | 改革文稿卷筒 | 挪開小石 | 805 年與同伴參與永貞革新 |
| 3 | 貶官文書 | 挖開積雪 | 改革失敗，被貶離京 |
| 4 | 行程布地圖 | 移枝拉出地圖 | 途中從邵州改貶永州 |
| 5 | 舊友送別信 | 撥開蘆葦 | 同伴分散、遠行的孤獨 |

墨鳥自行飛往當前物件，在實際樹枝、石頭或枯枝上落足等候，不會一直盤旋或追着學生。拾起後，往事立即在宣紙彈窗出現；關閉後，墨鳥飛回車上停棲。一次只能攜帶一件，歸還後才解鎖下一件。送別信固定最後，五件全部歸還才結束。重開會還原遮擋物、雪堆、手中物件、車上物件、已讀往事及腳印。

## 筆墨與立體表面

馬匹使用離線生成的連續肩背、頭頸與四腿曲面，並有平底蹄、短鬃與實際馬具。以 `node scripts/build-horse.mjs` 可用原生 Node.js 重建 `horse-v2.bin`，沒有新增建模依賴。馬車有微彎木板、非完全對稱的輪圈與布篷摺痕。五件行李有彎曲布面、紙張層次、繫帶、纖維及手寫圖文，均為實際可從不同角度觀看的立體曲面，另以透明插圖呈現拾取說明。

`brush-surface-atlas-v2.png` 的六格筆墨材質，分別用於馬毛淡墨、順木板方向的木紋、亞麻布、官帽折布、宣紙及乾筆墨鳥。UV／三向投影把圖像紋理貼在曲面上；柔和透明輪廓與薄墨暈減輕硬邊，沒有高光。宣紙彈窗以真正透明的不齊紙邊、紙纖維及可選取的繁體文楷文字組成。

出口道路在兩座大崖之間收窄，由馬車擋住；其餘山路仍相連。兩岸共用連續曲線，形成江灣與伸出的岸地，岸石留在陸上。保留灰藍／灰色水流、舟下破碎倒影與水紋、老翁與舟的浮沉、流動山霧、貼地雪粉、變強變弱的風、背風效果、樹形變化及約 21 秒內淡去的腳印。桌面降雪 7,600 片、觸控 4,200 片；沿路與兩岸約 630 簇枯草、蘆葦、稠密冬灌木、種莢、松針與斷枝，合成三個材質批次並避開路面。

## 素材與教學界線

原圖與繪畫材質由內建 imagegen 產生；完整提示詞及來源見 [ASSET-PROMPTS.md](ASSET-PROMPTS.md)。霞鶩文楷 TC 1.522 以 SIL OFL 1.1 隨附，來源與授權置於 `dist/assets/fonts/`。Three.js 0.186.1 以 MIT 授權隨附於 `dist/vendor/`。聲效使用原生 Web Audio，踏雪聲保留老師要求恢復的原有短雙層聲效與節奏。

馬車、墨鳥、散落行李、雪山路線、物件與送別信都是教學創作，不冒充柳宗元的遺物或真實貶謫路線。生平文字沿用教育局教材資料。詩中漁翁不是歷史人物的直接重演，情感也可有不同理解。不設詩句獎勵、三級提示、心情選擇或計分。此原型沒有學生帳戶、學習紀錄或課堂管理。
