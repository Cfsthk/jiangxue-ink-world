# 江雪・雪境漫遊

Three.js 半開放探索原型。繁體中文介面，依柳宗元〈江雪〉的山徑、寒江與孤舟設計。

## 本機開啟

需要 Node.js（只用來做語法檢查）及 Python 3。Three.js 已隨專案附上，不需安裝依賴。

```sh
npm run dev
```

開啟 http://127.0.0.1:4187/ 。請經 HTTP 開啟，不能直接雙擊 index.html。

```sh
npm run check
```

## 操作

- W A S D 或上／下方向鍵：行走；左／右方向鍵：轉身。
- 按住畫面拖曳：環顧。
- E／互動按鈕：走近松枝後落雪、江岸投石、凝望孤舟。
- C／呼喚按鈕：呼喚與回聲。
- Escape：暫停，亦可查看操作說明、選定的美術原圖或回到起點。
- 觸控裝置：左下搖桿移動，右側拖曳環顧。

## 視覺與原型範圍

選定基準圖是 `dist/assets/art-reference.png`（遠山加深灰、石灘加深之前的版本）。進場保留該原圖，再經霧色淡入實際可走動的三維場景。三維地形、岩塊、松樹、舟及人物均有立體表面：岩石用三向投影的乾筆岩紋，枝幹、木板和草蓑用沿物件方向的 UV 筆畫貼圖。近松可繞看；岩石採密分割不規則曲面與共享平滑法線，雪沿同一岩面以高度、坡度與墨暈混合，取消獨立幾何雪帽；雪面有淡墨顆粒、坡影及接地柔暈。江心不放石塊或孤立石柱；不可抵達的對岸有連續低雪岸。四層完整環繞的透明水墨山景，加上最遠連續淡山脊，覆蓋四方並隨遠近淡化。江水全部採灰藍與灰色深淺墨洗，破筆水紋緩流，遠岸以霧色銜接。孤舟與老翁一起輕輕浮沉，老翁以較低的坐姿垂釣，雙腳有木踏板支撐。八條相連山徑加上一條出口道路；原有山徑加闊約四成，沿地形細分貼合；路面有不規則泥灰、碎礫、留雪與乾筆紋。46棵近岸樹木分為直立層松、迎風斜松、虬曲疏松與冬日枯樹；對岸混合5棵立體冬樹與21棵變化比例及方向的墨松。沿路與兩岸約590簇冬季地被，包含枯草、蘆葦、灌木、種莢、松針落葉及斷枝，合成三個材質批次，並避開馬車及尋物地點。所有近岸樹幹與實際路面邊界至少相隔2.6米；遠樹使用墨松圖減少繪圖負擔。兩岸共四十四塊陸上灰雪岩與不規則灰墨砂礫帶，從山頂也能辨認。地形以連續坡度及墨洗混色取代逐三角面的雪／岩切換；道路末端與江面遠邊淡入周圍。天空持續降下大小不同的密雪（桌面7,600片、觸控4,200片），行走會留下左右交替、貼地的腳印，約二十一秒後完全淡去。這是可試玩的美術與互動原型，未包含正式課堂管理、學生紀錄或完整遊戲內容。

不設詩句獎勵、三級提示、心情選擇題或計分；0.8版加入老師批准的六件行李尋回流程。山路佈局、環境互動與天色均為教學上的藝術想像；詩中的情感可有不同理解。

## 0.7 環境互動

陣風把薄雪粉帶過地面，蘆葦與草莖由固定的根部彎動。以大岩石的高度、半徑和固定風向計算背風範圍，走進岩後時近處飛雪與風聲逐漸變弱，離開後恢復。低矮地被與落枝避開山路，位置包含風吹時的最大幅度。

孤舟的淡墨倒影取自實際船與漁翁幾何，投影在江面，以破碎水紋淡化；波紋緩緩散開。三片近地霧與兩片遠山霧慢慢流動、變濃或變淡。暫停時這些動畫一同停止。

## 0.8 山雪途中・尋回行李

老師批准的故事設定：805年前往永州途中，馬車掉落行李；物件及遇雪情節是教學創作。玩家從停在路邊的馬車後方開始。馬匹與木車面向新出口道路，原有山頂、林徑和江岸仍可探索。

六件行李是布書袋、官帽、改革文稿卷筒、貶官文書、行程布地圖和舊友送別信。前五件可自由選擇次序；每件須先與遮擋環境互動，再按E或觸控按鈕拾起。一次只能攜帶一件，須帶回車後放好，才能處理另一件。送別信只在前五件歸還後解鎖；第六件歸還即進入結束畫面。

互動分別是撥枝解帶、搖樹落帽、挪開小石、挖開薄雪、移開枯枝拉出地圖，以及撥開蘆葦。取物動畫暫停時會停止；挖雪以貼合地面的柔邊雪層逐步消退。物件按地形法線放置；手中模型會按畫面比例調整位置及大小。馬車、馬匹和行李均為可繞看的立體物件，使用現有筆墨材質、木紋與新繪製的淡墨馬毛紋理。

歸還前五件後，各出現一段簡短往事。左上「行囊」可查看位置線索，或重讀已歸還物件的往事；第六件的送別信及永州後記在結束畫面呈現。重開會清空進度、車上物件及手持物件，並還原遮擋物與積雪。
